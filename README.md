# Aurora Studio ✨

Aurora Studio is a modern and responsive luxury interior design landing page built using **HTML**, **CSS**, and **JavaScript**. The project focuses on clean aesthetics, elegant typography, smooth interactions, and a fully responsive user experience.

## 🚀 Live Demo

👉 https://kas232.github.io/aurora-studio/

## ✨ Features

- Modern and elegant UI
- Fully responsive design
- Sticky navigation bar
- Smooth scrolling
- Interactive animations
- Gallery section
- Mobile-friendly layout
- Clean and organized code

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## 📁 Project Structure

```
aurora-studio/
│── index.html
│── style.css
│── script.js
└── README.md
```

## 🎯 Purpose

This project was created to practice frontend web development and responsive UI design while building a professional landing page suitable for a luxury interior design brand.
